# Установка с нуля

Понадобится:

| Что | Зачем |
|---|---|
| **M5Stack Cardputer-Adv** (ESP32-S3, 8 МБ) | сам пульт. Прошивка рассчитана на версию **Adv** (другой аудиокодек), на обычном Cardputer микрофон работать не будет |
| **ПК с Windows 10/11** | на нём работает мост. Агенты и голос работают и на Linux/macOS, но режимы ОКНО и КЛАВ и быстрые команды — только Windows |
| **Python 3.12+** | мост (`python.org` или `winget install Python.Python.3.13`) |
| **Git** | скачать проект (`winget install Git.Git`) |
| **Claude Code** (по желанию) | режим CLAUDE: `npm install -g @anthropic-ai/claude-code`, затем `claude auth login` |
| **Приложение Codex** (по желанию) | режим CODEX: CLI берётся из установленного приложения Codex (или `codex` в PATH); войти в приложение |
| USB-C кабель с данными | прошивка и первая настройка устройства |

Нужен хотя бы один агент (Claude Code или Codex). Режимы ОКНО и КЛАВ работают и без них.

---

## 1. Скачать проект и поставить зависимости

```powershell
git clone https://github.com/<владелец>/m5v1.git
cd m5v1
py -3.13 -m venv .venv
.venv\Scripts\python -m pip install -r bridge\requirements.txt esptool
```

Для сборки прошивки из исходников добавьте `platformio` (см. раздел 4, вариант В).

## 2. Первый запуск моста

```powershell
cd bridge
..\.venv\Scripts\python -m m5bridge
```

При первом запуске:
- создаётся `bridge\config.toml` со **случайным токеном**. Токен даёт управление вашим ПК, поэтому
  файл никому не отдавайте (в git он не попадает);
- скачивается модель распознавания речи whisper `small` (~480 МБ, один раз);
- Windows спросит про доступ Python к сети: **разрешите для частной сети**. Иначе Cardputer
  не увидит мост (TCP 8765 и UDP 8766).

В логе появятся строки `LAN: http://192.168.x.x:8765` (адреса ПК) и найденные агенты.
Остановить мост: **Ctrl+C**.

## 3. Настроить под себя (`bridge\config.toml`)

Минимум, что стоит поменять:

```toml
[agent]
workdir = "C:/Users/Вы/Projects"   # папка, в которой работают агенты
```

По умолчанию агенты **только читают** файлы. Как дать им больше прав, добавить свои быстрые
команды и прочее — в [НАСТРОЙКА.md](НАСТРОЙКА.md).

## 4. Прошить Cardputer

Готовые файлы лежат на странице **Releases** репозитория:

| Файл | Для чего |
|---|---|
| `m5v1-cardputer-adv-<версия>.bin` | только приложение: для установки через M5Launcher (SD-карта или USB) |
| `m5v1-cardputer-adv-<версия>-full.bin` | вся флеш-память целиком: прошивка «с нуля» по адресу `0x0` |
| `SHA256SUMS.txt` | контрольные суммы |

> **Сначала сохраните заводскую прошивку** (один раз, только чтение):
> `powershell -ExecutionPolicy Bypass -File tools\backup_flash.ps1` → копия в `backups\`.
> Вернуть её: `.venv\Scripts\esptool --port COM3 write-flash 0 backups\<файл>.bin`.

**Вариант А. Прошить целиком (проще всего).** Заменяет всё, что было на устройстве.

```powershell
.venv\Scripts\esptool --chip esp32s3 --port COM3 write-flash 0x0 m5v1-cardputer-adv-<версия>-full.bin
```

COM-порт смотрите в Диспетчере устройств («Устройство с последовательным интерфейсом USB»).
Если порт не появляется, зажмите на Cardputer кнопку **G0** и подключите USB: включится
встроенный загрузчик ESP32-S3, «окирпичить» его нельзя.

Без установки Python можно прошить из браузера Chrome/Edge через
[ESP Tool](https://espressif.github.io/esptool-js/): адрес `0x0`, файл `…-full.bin`.

**Вариант Б. Рядом с другими прошивками, через [M5Launcher](https://github.com/bmorcelli/Launcher).**
Положите `m5v1-cardputer-adv-<версия>.bin` на SD-карту и установите из меню Launcher (SD). Можно
и по USB, без SD-карты: войдите в меню Launcher (включить → **Enter** на заставке) и выполните

```powershell
.venv\Scripts\python -I tools\launcher_install.py --port COM3 --wait 300 --replace m5v1=m5v1-cardputer-adv-<версия>.bin
```

**Вариант В. Собрать из исходников.**

```powershell
.venv\Scripts\python -m pip install platformio
cd firmware
..\.venv\Scripts\pio run -t upload
```

Собирайте из PowerShell или cmd: инструменты ESP-IDF не запускаются из Git Bash.

## 5. Связать Cardputer с мостом

Устройству нужны **ваша сеть Wi-Fi** и **токен моста**. Подключите Cardputer по USB, включите m5v1
и выполните из корня проекта:

```powershell
.venv\Scripts\python tools\provision.py --port COM3 --ssid "ИмяВашейСети"
```

Пароль Wi-Fi спрашивается в консоли и передаётся только по кабелю. Токен скрипт берёт из
`bridge\config.toml`.

Сеть можно добавить и на самом устройстве: **Fn+W** → выбрать сеть → ввести пароль → **Enter**.
Токен вводится только через `provision.py`.

Cardputer и ПК должны быть **в одной сети** (домашний роутер или мобильный хот-спот ПК). ESP32
работает только с Wi-Fi **2,4 ГГц**. Если хот-спот Windows раздаёт 5 ГГц, переключите диапазон в
его свойствах. Работа из другой сети описана в [НАСТРОЙКА.md](НАСТРОЙКА.md).

Когда всё готово, верхняя строка Cardputer станет **зелёной**: `CLAUDE <сеть> LAN`.

## 6. Автозапуск моста

```powershell
powershell -ExecutionPolicy Bypass -File tools\install_autostart.ps1
```

Создаёт задачу планировщика `m5bridge`: при входе в Windows без окна запускается менеджер моста,
а он запускает сам мост и перезапускает его, если тот упал. Панель управления:
**http://localhost:8764/**, где есть кнопки «Остановить»/«Запустить», «Перезапустить» и переключатель
«Автозапуск». Логи: `bridge\logs\bridge.log` (мост) и `bridge\logs\control.log` (менеджер).
Удалить задачу: тот же скрипт с ключом `-Remove`.

Чтобы пульт работал без присмотра, отключите сон ПК при питании от сети. Если используете
мобильный хот-спот Windows, выключите в его настройках энергосбережение.

## 7. Проверка

Пульт готов. Как пользоваться: [ИНСТРУКЦИЯ.md](ИНСТРУКЦИЯ.md).

Проверить мост без устройства:

```powershell
.venv\Scripts\python tools\test_bridge.py status
.venv\Scripts\python tools\test_bridge.py text "ответь одним словом: работает?"
.venv\Scripts\python tools\test_bridge.py text "сколько файлов в папке?" --mode codex
```

## Частые проблемы при установке

| Симптом | Решение |
|---|---|
| строка вверху жёлтая, «Мост не найден» | ПК и Cardputer в разных сетях, или брандмауэр блокирует Python (разрешите для частной сети) |
| «Неверный токен моста» | токен в `config.toml` менялся: снова выполните `provision.py` |
| агент отвечает «не авторизован» | `claude auth login` на ПК (если Claude у вас доступен только через VPN/прокси — с включённым VPN; мост передаёт агенту системный прокси Windows, `[agent].proxy = "auto"`) |
| CODEX: «агент не найден» | установите приложение Codex и войдите в него, или пропишите путь к `codex` в `[codex].bin` |
| Wi-Fi: «неверный пароль» / «сеть не найдена» | **Fn+W**, ввести пароль заново; проверить диапазон 2,4 ГГц |
