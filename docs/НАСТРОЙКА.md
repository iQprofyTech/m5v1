# Настройка моста (`bridge\config.toml`)

Файл создаётся при первом запуске моста. После правки перезапустите мост: **Ctrl+C** и снова
`python -m m5bridge`, а при автозапуске — `Stop-ScheduledTask m5bridge; Start-ScheduledTask m5bridge`.

## Права агента Claude (`[agent]`)

Агент — это Claude Code (`claude -p`), который мост запускает в папке `workdir`.
**По умолчанию он может только читать** файлы и искать в интернете. Это сделано намеренно:
неверно распознанная голосовая команда не должна сразу что-то менять.

Чтобы агент правил файлы и выполнял команды:

```toml
[agent]
workdir = "C:/Users/Вы/Projects"
permission_mode = "acceptEdits"
allowed_tools = ["Read", "Glob", "Grep", "Edit", "MultiEdit", "Write", "NotebookEdit",
                 "Bash", "WebSearch", "WebFetch", "Task", "TodoWrite"]
# Запрещено всегда, даже если попросить:
disallowed_tools = ["Bash(rm -rf:*)", "Bash(rmdir /s:*)", "Bash(del /s:*)", "Bash(Remove-Item -Recurse:*)",
                    "Bash(format:*)", "Bash(diskpart:*)", "Bash(git push --force:*)", "Bash(git reset --hard:*)",
                    "Bash(shutdown:*)", "Bash(Stop-Computer:*)", "Bash(Restart-Computer:*)"]
```

| Параметр | Что делает |
|---|---|
| `workdir` | папка, в которой работают агенты (Claude и Codex) |
| `add_dirs` | дополнительные папки вне `workdir` |
| `permission_mode` | `default` / `acceptEdits` / `plan` / `bypassPermissions` |
| `allowed_tools` / `disallowed_tools` | что агенту можно без вопросов / что нельзя никогда |
| `ask_permissions = true` | всё, чего нет в этих списках (Gmail, Календарь, команда вне списка…), агент спрашивает на Cardputer: **Enter** — да, **A** — всегда, **Esc** — нет |
| `confirm_voice = true` | голосовая команда сначала показывается на экране и ждёт **Enter**. Текст с клавиатуры выполняется сразу |
| `timeout_sec` | сколько агенту можно работать над одной командой (по умолчанию 900 с) |
| `proxy = "auto"` | агенту передаётся системный прокси Windows (если Claude у вас доступен только через VPN в режиме системного прокси); `none` — не передавать; или адрес `http://host:port` |

Запросы разрешений работают через MCP-помощник `bridge/m5bridge/approval_mcp.py`, который мост
подключает к `claude -p` (`--permission-prompt-tool`). Его адрес `/internal/permission` принимает
запросы только с этого ПК по одноразовому секрету, токен устройства к нему не подходит.

## Агент Codex (`[codex]`)

```toml
[codex]
bin = ""                  # пусто = codex из PATH или из установленного приложения Codex
sandbox = "read-only"     # read-only / workspace-write / danger-full-access
args = []                 # доп. аргументы `codex exec`, например ["-m", "gpt-5"]
```

- `read-only` (по умолчанию): Codex читает файлы и отвечает, но ничего не меняет.
- `workspace-write`: может менять файлы в `workdir`. **На Windows Codex в этом режиме просит
  права администратора (окно UAC) при каждом запуске.** Удалённо нажать «Да» некому, и задача
  повиснет.
- `danger-full-access`: без песочницы, как Claude с `Bash`. Включайте осознанно. Голосовые
  команды по-прежнему подтверждаются Enter.

Сессии Codex с Cardputer видны в приложении Codex (`~/.codex/sessions`).

## Быстрые команды ПК (`[commands]`)

В меню **Fn+P** кроме встроенных команд (громкость, медиа, окна, скриншот, блокировка) можно
добавить свои: «название» = команда оболочки Windows.

```toml
[commands]
"Проводник" = "explorer"
"Диспетчер задач" = "taskmgr"
"Браузер" = "start chrome"
"Музыка" = "start chrome https://music.yandex.ru"
```

Команды берутся только из этого файла: устройство может лишь выбрать команду из списка, но не
передать свою.

## Режим ОКНО (`[window]`)

```toml
[window]
reply_timeout = 180   # сколько ждать ответа в выбранном окне, с
settle_sec = 6        # ответ готов, когда текст в окне не меняется столько секунд
```

Для окна Claude Desktop ответ берётся из записи сессии (`~/.claude/projects`), и там действует
`[agent].timeout_sec`. Выбранное окно хранится в `bridge\window.json`.

## Распознавание речи (`[speech]`)

| Параметр | Что делает |
|---|---|
| `model` | модель faster-whisper: `tiny` / `base` / `small` / `medium` / `large-v3`. Без видеокарты `small` — разумный компромисс, `medium` точнее, но в 2–3 раза медленнее |
| `device` | `auto` / `cpu` / `cuda` |
| `language` | `ru`, `en`… (пусто = определять автоматически) |
| `prompt` | слова, которые стоит ожидать (названия проектов, сервисов, команды). Заметно уменьшает ошибки вида «чиновяки» вместо «черновики» |

Речь распознаётся на ПК локально, в интернет запись не уходит. Последняя запись сохраняется в
`bridge\logs\last_voice.wav`.

## Где смотреть, что делали агенты

| Где | Что там |
|---|---|
| экран Cardputer | каждое действие строкой `* Bash: git status`, `* Edit: …`, затем итог |
| `bridge\logs\agent.log` | команда, все действия, ответ, стоимость. Вживую: `Get-Content bridge\logs\agent.log -Wait -Encoding utf8` |
| `bridge\logs\bridge.log` | лог самого моста |
| `~/.claude/projects/<папка>/*.jsonl` | полные стенограммы сессий Claude Code |
| `claude --resume` в папке `workdir` | открыть сессию Claude в терминале и продолжить вручную |
| приложение Codex | сессии Codex |

## Доступ из другой сети

Дома Cardputer находит мост сам (UDP broadcast). Чтобы работать из другой сети (кафе, телефон в
режиме модема), нужен адрес моста, доступный из интернета. **Порт на роутере открывать не
нужно**: используйте туннель с HTTPS-адресом.

**Cloudflare Tunnel** (бесплатно, нужен домен в Cloudflare):

```powershell
winget install Cloudflare.cloudflared
cloudflared tunnel login
cloudflared tunnel create m5bridge
cloudflared tunnel route dns m5bridge m5.ваш-домен.ru
cloudflared tunnel run --url http://127.0.0.1:8765 m5bridge
```

Быстрая проверка без домена: `cloudflared tunnel --url http://127.0.0.1:8765` даёт временный
адрес `*.trycloudflare.com`, который меняется при каждом запуске.

**Tailscale Funnel:** `tailscale funnel 8765` даёт адрес вида `https://<pc>.<tailnet>.ts.net`.

Записать адрес в устройство:

```powershell
.venv\Scripts\python tools\provision.py --port COM3 --remote-url https://m5.ваш-домен.ru
```

Порядок подключения на устройстве: фиксированный LAN-адрес (`--lan-url`) → поиск в локальной
сети → удалённый адрес. Верхняя строка показывает `LAN` или `NET`.

**Безопасность:**
- все запросы требуют токен. Храните `config.toml` в секрете; при утечке смените `token` и
  запишите новый в устройство через `provision.py`;
- прошивка не проверяет TLS-сертификат туннеля (`setInsecure`): токен защищён от пассивного
  перехвата, но не от активной подмены в чужой сети. Для лучшей защиты включите в Cloudflare
  Access сервисный токен или пользуйтесь только доверенными сетями;
- если мост должен быть доступен только через туннель, поставьте `[server] host = "127.0.0.1"`.

## Разработка

```powershell
cd bridge; ..\.venv\Scripts\python -m pip install -r requirements-dev.txt
..\.venv\Scripts\python -m pytest -q
```

Прошивка: `firmware/` (PlatformIO, pioarduino / arduino-esp32 3.x). Сборка релиза:
`.venv\Scripts\python tools\make_release.py` (после `pio run`).
Отладочные команды по USB (115200 бод): `PING`, `INFO`, `WIFI` (переподключиться и вывести причину
отказа), `MIC 1000` (уровень микрофона).
