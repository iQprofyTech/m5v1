# Cardputer m5v1 — инструкция пользователя

Cardputer — карманный пульт для этого ПК. С него можно:

- давать задания агентам **Claude Code** и **Codex** голосом или текстом и читать их ответы на экране;
- писать в **любое открытое окно** ПК: чат Claude Desktop, Codex, ChatGPT или WhatsApp в браузере;
- управлять ПК как **клавиатурой и мышью**;
- запускать **быстрые команды**: громкость, музыка, окна, блокировка.

---

## 1. Включение

1. Включите Cardputer переключателем сбоку.
2. Появится заставка **Launcher**. Ничего не нажимайте: через несколько секунд запустится **m5v1**.
   - **2** — сразу запустить m5v1;
   - **1** — заводская прошивка M5Stack (компас, GPS и пр.);
   - **Enter** — меню Launcher (нужно только для обновления прошивки).
3. m5v1 подключится к Wi-Fi и найдёт мост на ПК. Строка вверху станет зелёной:

```
CLAUDE HomeWiFi LAN                    87%
 режим  сеть Wi-Fi связь с ПК      батарея
```

| Цвет верхней строки | Значение |
|---|---|
| зелёный | всё подключено, можно работать |
| жёлтый | Wi-Fi есть, моста нет (ПК выключен или мост не запущен) |
| красный | нет Wi-Fi |

**Что должно быть включено на ПК:** сам ПК (не в спящем режиме), сеть Wi-Fi, в которой находится
Cardputer (роутер или мобильный хот-спот ПК), VPN (если Claude у вас доступен только через него) и
мост m5v1. Мост запускается сам при
входе в Windows.

Провод не нужен: Cardputer работает от батареи. По USB его только заряжают и прошивают.

---

## 2. Режимы

Режим переключает **Tab** по кругу: **CLAUDE → CODEX → ОКНО → КЛАВ → CLAUDE…**
Текущий режим написан слева вверху. Tab работает в любом режиме.

| Режим | Куда уходит голос и текст | Ответ |
|---|---|---|
| **CLAUDE** | агент Claude Code на ПК (папка `[agent].workdir` из `config.toml`) | на экране Cardputer |
| **CODEX** | агент Codex на ПК | на экране Cardputer |
| **ОКНО** | окно ПК, выбранное через **Fn+O** | считывается с экрана этого окна и приходит на Cardputer |
| **КЛАВ** | клавиши уходят на ПК, голос печатается в активное окно | «Напечатано на ПК» |

**Как выбрать режим:**
- надо что-то **сделать на ПК** (файлы, проекты, код, поиск в интернете) → **CLAUDE** или **CODEX**;
- надо **написать в открытый чат** (Claude Desktop, ChatGPT, мессенджер) → **ОКНО**;
- надо **нажать кнопки** на ПК, листать страницу, двигать мышь → **КЛАВ**.

> Если на любой запрос приходит «Напечатано на ПК», вы в режиме **КЛАВ**: нажмите **Tab**.

---

## 3. Голосовая команда (CLAUDE, CODEX, ОКНО)

1. **Нажмите и держите G0** (кнопка на боковой грани) и говорите. Внизу виден уровень звука.
2. **Отпустите G0.** Появится «Распознаю речь…», затем текст: `Вы: …`.
3. Проверьте текст и нажмите **Enter**, чтобы выполнить, или **Fn+`** (Esc), чтобы отменить.
4. Пока идёт работа, видны действия агента: `* Bash: git status`, `* Edit: …`.
5. В конце приходит ответ и звучит сигнал.

Без удержания кнопки: **Fn+Space** начинает запись, любая клавиша её заканчивает.

**Текстом:** наберите команду на клавиатуре Cardputer и нажмите **Enter**. Подтверждать не нужно.

**Звуки:**

| Звук | Значение |
|---|---|
| короткий | подтвердите голосовую команду (Enter) |
| двойной писк | агент спрашивает разрешение |
| высокий | готово, ответ на экране |
| низкий | ошибка |

---

## 4. Разрешения агента (режим CLAUDE)

Если агенту нужно что-то вне разрешённого списка (Gmail, Календарь, необычная команда),
Cardputer дважды пищит и показывает `? Разрешить: Gmail: list_drafts`.

| Клавиша | Действие |
|---|---|
| **Enter** | разрешить один раз |
| **A** | разрешать это всегда (до перезапуска моста) |
| **Fn+`** (Esc) | запретить (повторное Esc отменяет всю задачу) |

Без ответа в течение 3 минут действие запрещается.

---

## 5. Режим ОКНО

1. **Fn+O** открывает список окон ПК (вида `firefox: WhatsApp — Mozilla Firefox`).
2. Выберите окно клавишами **;** (вверх) и **.** (вниз), нажмите **Enter**. Окно выйдет на передний
   план, режим сам станет **ОКНО**. Выбор запоминается.
3. Скажите или напишите сообщение: мост вставит его в поле ввода окна и нажмёт Enter.
4. Ответ мост читает с экрана окна. Он приходит, когда текст в окне перестаёт меняться (~6 с).
   Для окна **Claude Desktop** ответ берётся точно из записи сессии, даже если агент работает долго.

**Советы:**
- Для голосовых команд в Claude Desktop откройте **отдельную сессию**. Иначе команды смешаются с
  другой работой, а сообщения в занятую сессию встают в очередь.
- Пока ждёте ответ, не печатайте на ПК в этом окне: мост может принять ваш набор за ответ.
- Если окно закрыли, выберите его снова через **Fn+O**.

---

## 6. Режим КЛАВ: клавиатура и мышь ПК

| На Cardputer | На ПК |
|---|---|
| буквы, цифры, знаки | печатаются в активном окне |
| **Enter** / **Del** | Enter / Backspace |
| **Ctrl+буква** | Ctrl+буква (Ctrl+C, Ctrl+V, Ctrl+Z, Ctrl+S…) |
| **Alt+буква**, **Alt+Tab** | Alt+буква, переключение окон |
| **Opt+Tab** | клавиша Tab |
| **Fn+;** **Fn+.** **Fn+,** **Fn+/** | стрелки ↑ ↓ ← → |
| **Fn+`** / **Fn+Del** | Esc / Delete |
| **Opt+;** **Opt+.** **Opt+,** **Opt+/** | мышь вверх / вниз / влево / вправо |
| **Opt+Enter** / **Opt+Space** | левый / правый клик |
| **Opt+[** / **Opt+]** | прокрутка вверх / вниз |
| **G0** (голос) | диктовка: сказанное печатается в активное окно (кириллица тоже) |
| **Fn+O** | переключиться на другое окно ПК |

Клавиатура Cardputer латинская. Русский текст вводите голосом (G0) или в режимах CLAUDE, CODEX, ОКНО.

---

## 7. Быстрые команды ПК (Fn+P)

**Fn+P** открывает меню. Выбор клавишами **;** и **.**, **Enter** выполняет. Меню остаётся открытым:
громкость удобно нажимать несколько раз. Выход — **Fn+`**.

Встроенные команды: Громкость + / −, Звук вкл/выкл, Пауза/играть, Следующий/Предыдущий трек,
Alt+Tab, Рабочий стол (Win+D), Свернуть/Развернуть окно, Закрыть окно (Alt+F4), Скриншот,
Заблокировать ПК. Плюс ваши команды из `config.toml`.

Свои команды добавляются в `bridge\config.toml` (в папке m5v1 на ПК), раздел `[commands]`
(после правки перезапустите мост, см. раздел 10):

```toml
[commands]
"Открыть браузер" = "start chrome"
"Яндекс Музыка" = "start chrome https://music.yandex.ru"
```

## 8. Все горячие клавиши

| Клавиши | Действие | Где |
|---|---|---|
| **Tab** | сменить режим | везде |
| **G0** (держать) | голос | везде |
| **Fn+Space** | начать / закончить запись | везде |
| **Enter** | отправить текст / подтвердить / разрешить | везде |
| **Fn+`** (Esc) | отменить задачу / запретить / закрыть меню | везде |
| **Fn+O** | выбрать окно ПК | везде |
| **Fn+P** | быстрые команды ПК | везде |
| **Fn+N** | новая сессия агента (контекст с нуля) | CLAUDE, CODEX |
| **Fn+L** | выбрать прошлую сессию агента | CLAUDE, CODEX |
| **Fn+;** / **Fn+.** | прокрутка экрана вверх / вниз | кроме КЛАВ |
| **Fn+W** | сети Wi-Fi | везде |
| **Fn+R** | переподключиться к Wi-Fi и мосту | везде |
| **Fn+H** | подсказка по клавишам текущего режима | везде |

**Меню** (Wi-Fi, окна, команды, сессии): **;** вверх, **.** вниз, **Enter** выбрать, **`** выйти.

---

## 9. Сессии агентов

- Агент помнит разговор: следующая команда продолжает текущую сессию.
- **Fn+N** начинает новую сессию, **Fn+L** открывает список прошлых. Списки у Claude и Codex свои.
- Сессии Claude можно открыть на ПК: в рабочей папке агента (`[agent].workdir`) выполните `claude --resume`.
- Сессии Codex видны в приложении Codex.
- Журнал всех команд, действий и ответов: `bridge\logs\agent.log` в папке m5v1.

---

## 10. Wi-Fi и мост

**Добавить сеть:** **Fn+W** → выбрать сеть → **Enter** → ввести пароль (заглавные буквы через **Aa**)
→ **Enter**. Для сохранённой сети пароль подставляется сам: просто **Enter**. **Del** в списке
удаляет сеть. Хранится до 8 сетей.

**Мост на ПК:**

| Что | Где |
|---|---|
| программа | `<папка m5v1>\bridge\` |
| настройки | `<папка m5v1>\bridge\config.toml` (подробно: [НАСТРОЙКА.md](НАСТРОЙКА.md)) |
| логи | `<папка m5v1>\bridge\logs\` |
| автозапуск | задача планировщика Windows `m5bridge`, включается и выключается на панели |
| панель | **http://localhost:8764/** (с управлением) или http://localhost:8765/ |

**Остановить, запустить или перезапустить мост** можно кнопками в шапке панели. Там же
переключатель **«Автозапуск»**: запускать ли мост при входе в Windows. Он включает и выключает
задачу `m5bridge` в Планировщике заданий (в списке «Автозагрузка» Диспетчера задач её нет).

На панели видно, на связи ли Cardputer: «на связи» или «не в сети · был N мин назад». Пока
устройство ничего не отправляет, мост раз в 5 секунд проверяет его пингом.

Без панели перезапустить мост можно так (PowerShell):

```powershell
Stop-ScheduledTask m5bridge; Start-ScheduledTask m5bridge
```

## 11. Если что-то не работает

| Что видно | Что делать |
|---|---|
| на любой запрос «Напечатано на ПК» | вы в режиме КЛАВ: **Tab** |
| верхняя строка красная, «Wi-Fi не подключён - …» | причина написана в строке: «неверный пароль» → **Fn+W** и ввести заново; «сеть не найдена» → включить роутер / хот-спот ПК (нужен диапазон 2,4 ГГц) |
| верхняя строка жёлтая, «Мост недоступен» | ПК спит, или мост не запущен (перезапустить, раздел 10) |
| «Окно не выбрано или закрыто» | **Fn+O** и выбрать окно |
| в режиме ОКНО ответ «новый текст в нём не появился» | окно не ответило за 3 минуты, или текст не дошёл: проверьте окно на ПК |
| «Консольный Claude Code заблокирован… / не авторизован» | на ПК войти заново: `claude auth login` (если нужен VPN — с включённым VPN) |
| Codex отвечает ошибкой | проверить, что приложение Codex установлено и вы в нём вошли |
| речь распознаётся с ошибками | говорить ближе (15–20 см), короче и чётче; перед Enter всегда смотреть на текст |
| устройство не реагирует | **Fn+`**, затем **Fn+R**; если не помогло — выключить и включить |

Голос распознаётся на ПК локально (whisper), запись не уходит в интернет. Последняя запись лежит
в `bridge\logs\last_voice.wav`: по ней удобно проверять микрофон.
